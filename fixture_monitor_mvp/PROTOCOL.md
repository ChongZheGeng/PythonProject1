# STM32—上位机通信协议

## 1. 基本约定

- 物理链路：USB 转串口；
- 默认波特率：115200；
- 编码：UTF-8；
- 每条消息以 `\n` 结束；
- 第一版采用可读文本协议，便于串口助手调试。

## 2. 遥测数据

STM32 周期性发送：

```text
F:1520.5,AX:0.12,AY:0.08,AZ:0.99,U:36.2,S:2
```

必选字段：`F`、`AX`、`AY`、`AZ`、`U`、`S`。字段顺序可以变化，额外字段会被上位机忽略。

## 3. 参数命令

```text
SET,<目标夹紧力N>,<Kp>,<Ki>,<Kd>
```

示例：

```text
SET,1500.000,1.200000,0.080000,0.030000
```

STM32 应校验数值范围，并只在参数合法时覆盖当前控制参数。

## 4. 控制命令

```text
START
STOP
RELEASE
EMERGENCY
ZERO
```

- `START`：启动夹紧力闭环；
- `STOP`：停止调节并进入安全保持或待机；
- `RELEASE`：松开工件；
- `EMERGENCY`：立即停止执行机构；
- `ZERO`：仅在无载状态下执行夹紧力调零。

## 5. 安全要求

- 夹紧力上限、执行机构行程限位、过流和急停必须在 STM32 本地实现；
- 串口中断后，STM32 不应继续执行新的运动命令；
- 上位机报警用于监视，不应作为唯一安全保护；
- PID 控制周期由 STM32 保证，上位机刷新速率不参与实时控制。
